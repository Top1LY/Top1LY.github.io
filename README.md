# 主播歌单站

一套给直播用的网页歌单：**多主播共享一个站点**，每位主播有自己的主页；歌单本身是贴在直播画面上的透明悬浮层，每条曲目 = **分类标签 + 歌名 + 歌手**，还带**主播头像、名字**和一跳就到 **B站主页 / 直播间**的按钮。

零依赖、零构建，推到 GitHub Pages 就能用。

## 四个页面

| 页面 | 地址 | 用途 |
|---|---|---|
| 首页 · 主播大厅 | `index.html` | 一张卡片一位主播，点进去就是她的主页 |
| 主播个人主页 | `profile.html?id=yuki` | 头像 / 简介 / **可搜索、可按标签筛**的歌单 / 点歌名即复制 / B站跳转 |
| 悬浮层 | `overlay.html?id=yuki` | **OBS 挂的就是它**，透明背景，直接叠在直播画面上 |
| 配置台 | `studio.html?id=yuki` | 选主播 → 调外观、调色、调标签配色、设背景图 → 生成地址，右侧实时预览 |

> 首页可以给访客看，也可以只当自己的导航页。悬浮层是唯一需要塞进 OBS 的地址。
> 主页上不再直接摆出悬浮层长地址，而是两个入口按钮：**「OBS 悬浮层地址 →」** 进配置台，
> **「看效果」** 直接在浏览器里开一层预览（带示意背景）。

## 部署（3 步）

1. 把整个文件夹推到名为 `<用户名>.github.io` 的仓库（本仓库对应 `https://top1ly.github.io/`）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存。
3. 等一分钟，访问站点首页能看到主播卡片就成功了。

## OBS 接入

1. 来源 → `+` → **浏览器**。
2. URL 填悬浮层地址：打开某位主播的主页 → 点 **「OBS 悬浮层地址 →」** 进配置台 →
   右边调好外观 → 复制顶部那条地址。它长这样：
   `https://top1ly.github.io/overlay.html?id=yuki&style=compact`
3. 宽高和画布一致（如 1920×1080），勾选 **「透明背景」**。
4. 勾选「当场景激活时刷新浏览器」，歌单改了重进场景就是新的。

> 页面本身全透明，画面上不会出现任何白底。
> 注意：OBS 的浏览器源默认不接受鼠标点击，所以悬浮层上的「B站 / 直播间」按钮、以及
> **点歌名复制**在直播画面里都是**展示/无效**的——观众看到的是你的名字和按钮，想跳转请让他们去你的主页或简介里的链接。在浏览器里直接打开这条地址时，两者都是真能用的。

## 加一位主播

1. 复制 `streamers/yuki.json` 成 `streamers/你的id.json`，改里面的信息与 `songs`。
2. 在 `data/streamers.json` 的 `streamers` 数组里加一条同名 id 的条目（首页名册）。
3. 把头像图片丢进 `assets/avatars/`，在 `avatar` 字段填路径。

之后就有一条专属地址：`overlay.html?id=你的id`。

## 参数速查

### 外观与排版

| 参数 | 说明 | 默认 |
|---|---|---|
| `id` | 主播 id，自动读 `streamers/<id>.json` | 名册里的 `defaults.streamer` |
| `src` | 直接指定数据文件路径 | — |
| `style` | `compact` 紧凑窄版 / `banner` 大字大屏 / `minimal` 简约无标签 | `compact` |
| `size` | 歌名字号（px）。**标签、歌手、间距、圆角、阴影全部跟着等比缩放** | 按外观 |
| `max` | 最多显示前 N 条 | 全部 |
| `playing` | 标记「正在播放」的序号（从 0 开始） | 不标记 |
| `refresh` | 自动重读数据的间隔（秒），`0` 关闭 | `60` |
| `radius` | 圆角倍率（`1.5` = 放大 50%） | `1` |
| `blur` | 毛玻璃强度倍率 | `1` |
| `font` | 覆盖字体族，如 `font=HarmonyOS%20Sans%20SC` | 系统黑体栈 |

### 显示开关

| 参数 | 说明 |
|---|---|
| `identity=0` | 隐藏整个主播身份行（简约版默认隐藏） |
| `avatar=0` | 隐藏主播头像 |
| `link=0` | 隐藏 B站 / 直播间 按钮 |
| `tags=0` | 隐藏分类标签 |
| `panel=0` | 去掉条目半透明底板，只留文字 |
| `title=0` | 隐藏歌单标题行；也可以写 `title=今晚随机唱见` 自定义 |
| `preview=1` | 加一层示意背景，方便在浏览器里看效果（直播别加） |

### 筛选（只显示歌单的一部分）

| 参数 | 说明 |
|---|---|
| `q` | 关键词，匹配 **歌名 / 歌手 / 标签**；空格分隔多个词表示「都要命中」 |
| `tag` | 按标签过滤，多个标签用 `,` 分隔表示「命中任一即可」，如 `tag=日语,中文` |

> 过滤发生在「取前 N 条」之前，所以 `q=yoasobi&max=5` = 先筛出这位歌手的曲子，再取前 5 条。
> 悬浮层上会显示 `已显示 / 总数`，右上角那行小字只在真的筛过之后才出现。
> 关键词里有中文或空格时记得转义：`q=%E5%A4%9C` 、多个词用 `%20` 连。

### 标签配色

标签默认「一个标签一个色相」，色相由标签名稳定推导（写新标签名会自动配色）。想收敛颜色就用这两条：

| 参数 | 说明 |
|---|---|
| `tagMode` | `auto` 每个标签自己的色相（默认）/ `accent` **全部跟着主色走**（最干净，推荐在直播里用）/ `custom` 用下面的 `tagColors` 逐条指定 |
| `tagColors` | 逐标签指定颜色，格式 `标签:%23色值`，逗号分隔：`tagColors=日语:%23FF6FA5,中文:%23FF6B4A` |

> 单个曲目在数据里写的 `"color": "#FF0000"` 优先级最高，任何模式下都会盖掉上面两条。
> 配置台里改完会即时反映到预览与生成的地址上；`tagMode=auto` 因为就是默认值，不会写进地址。

### 自定义背景图

默认**不启用**，OBS 透明背景不受影响。想给主页/预览加一层氛围底图再开：

| 参数 | 说明 | 默认 |
|---|---|---|
| `bgImage` | 背景图地址（相对路径或外链；URL 里的 `#` 写 `%23`） | 无 |
| `bgImgAlpha` | 底图透明度 `0`–`1` | `0.35` |
| `bgImgBlur` | 底图模糊像素 | `0` |

> 建议把图片放进 `assets/backgrounds/`，用相对路径引用，如 `assets/backgrounds/night.jpg`。
> 开着背景图时画面上会多一层不透明像素——**要给 OBS 用就别开**，它的主场是主页和浏览器预览。

### 配色

| 参数 | 说明 |
|---|---|
| `theme` | 见下方主题清单（共 14 套） |
| `accent` | 主色：标题高亮、直播间按钮、头像描边、正在播放标记 |
| `accent2` | 主色浅色端（头像与色卡渐变） |
| `bg` | 条目底板色 |
| `bgOpacity` | 底板通透度 `0`–`1` |
| `color` / `sub` | 歌名 / 歌手文字色 |
| `tagAlpha` / `tagSat` / `tagLight` | 标签的不透明度、饱和度、明度 |

颜色写任意 hex 即可（URL 里 `#` 要写成 `%23`）。没写的项沿用所选主题的值，所以**改一个不会连带动其它**。

**14 套预设主题**

- 深色系：`aurora` 极光 / `sakura` 樱花 / `midnight` 午夜 / `neon` 霓虹 / `sunset` 晚霞 / `ocean` 深海 / `violet` 紫罗兰 / `forest` 森野 / `rose` 玫瑰 / `cyber` 赛博 / `mono` 极简灰
- 浅色系：`light` 浅色 / `cream` 奶油 / `mint` 薄荷

> 浅色系主题内部统一用柔和阴影，切过去不会出现「浅底配浓黑投影」的脏边。


## 主题与配色怎么设计的

四件事值得说清楚，因为它们直接决定你后面改起来顺不顺手：

1. **十四套预设主题打底，单点颜色可覆盖。** 主题是一组值（主色 / 底板 / 文字 / 标签色感 / 阴影强度），URL 参数只在需要时覆盖其中一项。想做浅色歌单就用 `theme=light`，不用逐项挑色。
2. **标签的色相可以「放开」也可以「收住」。** 默认 `tagMode=auto` 让每个标签保留自己的色相，只让饱和度与明度跟着主题走，所以换主题时整排标签会一起变调，不会出现「一个粉一个绿各说各话」；写数据里没出现过的新标签名（比如「粤语」「打歌」）会自动分配一个稳定色相。觉得颜色太花就切 `tagMode=accent`，所有标签统一用主色，一条地址就安静下来了；折中方案是 `tagMode=custom` + `tagColors`，只给几个标签钉色。想钉死单条曲目就写 `"color": "#FF0000"`，它永远优先级最高。
3. **主色上的文字色是算出来的，不是写死的。** `--accent-fg` 会按主色亮度自动决定用深字还是白字，所以你把 `accent` 改成很深的蓝，按钮上的字会自动翻成白色。
4. **背景图是可选项，默认关。** 一开就会给整层铺上不透明像素，OBS 那边就没有「透明背景」了——所以它默认不写进地址，只在你要给主页做氛围时手动打开。

## 数据格式

`streamers/yuki.json`：

```json
{
  "id": "yuki",
  "name": "星野雪",
  "handle": "HoshinoYuki",
  "avatar": "assets/avatars/yuki.jpg",
  "bio": "每晚 20:00 开播｜日语流行与唱见",
  "intro": "主页上展示的完整简介",
  "tags": ["日语", "唱见", "治愈"],
  "theme": "aurora",
  "accent": "#7C9CFF",
  "bilibili": {
    "space": "https://space.bilibili.com/100001",
    "live": "https://live.bilibili.com/200001"
  },
  "title": "今日歌单",
  "updated": "2 小时前",
  "songs": [
    { "tag": "日语", "name": "夜に駆ける", "artist": "YOASOBI" },
    { "tag": "中文", "name": "起风了", "artist": "买辣椒也用券", "color": "#FF6B4A" }
  ]
}
```

`data/streamers.json` 是首页用的名册（站点标题 + 每位主播的展示信息，不含歌曲），首页会再各读一份 `streamers/<id>.json` 统计曲目数。

名册里每位的 `themes` 是**推荐主题清单**，配置台会把它排在色卡最前面并打一个小星标，后面才跟其余主题——这样每位主播挑色时先看到的是「她这套人设适合的」，而不是 14 个色块平铺。

```json
{
  "id": "yuki",
  "theme": "aurora",
  "themes": ["aurora", "ocean", "violet", "mint"]
}
```

`themes` 不写也能用，只是配置台会退回「全部主题顺序」。曲目上的 `color` 是这条曲子的标签强制色，写了就永远以它为准。

内置标签色相（`tagMode=auto` 时的稳定取值）：`日语` `中文` `英文` `高音` `韩语` `电音` `粤语` `纯音乐` `RAP`。其它标签名会自动算一个色相，写进 `tagColors` 就能钉住。

## 设计要点

- **所有尺寸锚定在歌名字号上。** 标签、歌手、间距、圆角、阴影全部按 `--fs` 等比缩放，所以调 `size` 是整体放大，不会出现「字大了标签还那么小」的割裂感。
- **大字版的身份行是单独一套比例。** 歌名放大到 34px 时，头像和按钮会相对收缩（`1.55×` 而不是 `2.38×` 字号），否则底部整条会被撑得又高又笨。
- **文字阴影跟随字号**（用 `em` 计算），调到多大都不会糊在复杂画面上；浅色主题下会自动换成贴着字形的一圈细白晕，避免深色文字被阴影漂白。
- **长歌名靠 `overflow-wrap: anywhere` 自然换行**，不截断也不撑破容器，无空格的英文长名同样能断。
- **点歌名即复制，复制的格式是 `歌名 - 歌手`。** 主页里歌名自身可点；鼠标移到某一行时行尾才浮出一个复制按钮，免得整列都是小图标把歌单弄花。复制成功底部弹一条轻提示，失败会改用橙色提示——因为浏览器只在 https / localhost 下给剪贴板权限。
- **筛选是「先筛后截」。** 搜索词按空格拆成多个条件，彼此是「与」；标签之间是「或」——想找「日语里 YOASOBI 的那几首」就是选标签 `日语` + 搜 `yoasobi`。右上角只在真的筛过之后才显示 `已显示 / 总数`。

## 文件结构

```
index.html                 首页 · 主播大厅
profile.html               主播个人主页（搜索 / 标签筛选 / 点歌名复制）
overlay.html               悬浮层（OBS 用的就是它）
studio.html                配置台：调参 + 实时预览 + 生成地址
data/streamers.json        站点配置 + 主播名册（含每位推荐的 themes）
streamers/<id>.json        每位主播的信息与歌单（改这个）
assets/theme.js            14 套主题预设 + 颜色/URL 工具
assets/common.js           参数解析 / 数据加载 / 标签配色 / 筛选 / 复制提示
assets/overlay.css         悬浮层样式（三套外观）
assets/overlay.js          悬浮层逻辑
assets/site.css            首页 / 主页 / 配置台样式
assets/home.js             首页逻辑
assets/profile.js          主播主页逻辑（搜索、标签栏、复制）
assets/studio.js           配置台逻辑
assets/avatars/            头像图片（可选）
assets/backgrounds/        自定义背景图（可选）
```

> 头像不是必填项。不配置时用「名字首字 + 主色渐变」自动生成，配色跟着该主播的 `accent` 走；
> 想换成真实图片，新建 `assets/avatars/` 放进去，再在 `streamers/<id>.json` 里加 `avatar` 字段。
> 背景图同理，放 `assets/backgrounds/`，在配置台里填相对路径即可。
>
> 本页面的数据是用 `fetch` 读的，所以**必须通过 http(s) 访问**（本地用
> `python -m http.server` 起一个，或直接推到 GitHub Pages）。直接用
> `file://` 双击打开会读不到 json。
