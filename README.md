# 主播歌单站

一套给直播用的网页歌单：**多主播共享一个站点**，每位主播有自己的主页；歌单本身是贴在直播画面上的透明悬浮层，每条曲目 = **分类标签 + 歌名 + 歌手**，还带**主播头像、名字**和一跳就到 **B站主页 / 直播间**的按钮。

零依赖、零构建，推到 GitHub Pages 就能用。

## 四个页面

| 页面 | 地址 | 用途 |
|---|---|---|
| 首页 · 主播大厅 | `index.html` | 一张卡片一位主播，点进去就是她的主页 |
| 主播个人主页 | `profile.html?id=yuki` | 头像 / 简介 / 完整歌单 / B站跳转 / OBS 地址一键复制 |
| 悬浮层 | `overlay.html?id=yuki` | **OBS 挂的就是它**，透明背景，直接叠在直播画面上 |
| 配置台 | `studio.html` | 选主播 → 调外观、调色、调字号 → 生成地址，右侧实时预览 |

> 首页可以给访客看，也可以只当自己的导航页。悬浮层是唯一需要塞进 OBS 的地址。

## 部署（3 步）

1. 把整个文件夹推到名为 `<用户名>.github.io` 的仓库（本仓库对应 `https://top1ly.github.io/`）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存。
3. 等一分钟，访问站点首页能看到主播卡片就成功了。

## OBS 接入

1. 来源 → `+` → **浏览器**。
2. URL 填从主播主页复制的那条地址，例如
   `https://top1ly.github.io/overlay.html?id=yuki&style=compact`
3. 宽高和画布一致（如 1920×1080），勾选 **「透明背景」**。
4. 勾选「当场景激活时刷新浏览器」，歌单改了重进场景就是新的。

> 页面本身全透明，画面上不会出现任何白底。
> 注意：OBS 的浏览器源默认不接受鼠标点击，所以悬浮层上的「B站 / 直播间」按钮在直播画面里是**展示用**的——观众看到的是你的名字和按钮，想跳转请让他们去你的主页或简介里的链接。在浏览器里直接打开这条地址时，按钮是真能点的。

## 加一位主播

1. 复制 `streamers/yuki.json` 成 `streamers/你的id.json`，改里面的信息与 `songs`。
2. 在 `data/streamers.json` 的 `streamers` 数组里加一条同名 id 的条目（首页名册）。
3. 把头像图片丢进 `assets/avatars/`，在 `avatar` 字段填路径。

之后就有一条专属地址：`overlay.html?id=你的id`。

## 参数速查

### 外观与排版

| 参数 | 说明 | 默认 |
|---|---|---|
| `id` | 主播 id，自动读 `streamers/<id>.json` | 名册里的 `defaults.streamer` |
| `src` | 直接指定数据文件路径 | — |
| `style` | `compact` 紧凑窄版 / `banner` 大字大屏 / `minimal` 简约无标签 | `compact` |
| `size` | 歌名字号（px）。**标签、歌手、间距、圆角、阴影全部跟着等比缩放** | 按外观 |
| `max` | 最多显示前 N 条 | 全部 |
| `playing` | 标记「正在播放」的序号（从 0 开始） | 不标记 |
| `refresh` | 自动重读数据的间隔（秒），`0` 关闭 | `60` |
| `radius` | 圆角倍率（`1.5` = 放大 50%） | `1` |
| `blur` | 毛玻璃强度倍率 | `1` |
| `font` | 覆盖字体族，如 `font=HarmonyOS%20Sans%20SC` | 系统黑体栈 |

### 显示开关

| 参数 | 说明 |
|---|---|
| `identity=0` | 隐藏整个主播身份行（简约版默认隐藏） |
| `avatar=0` | 隐藏主播头像 |
| `link=0` | 隐藏 B站 / 直播间 按钮 |
| `tags=0` | 隐藏分类标签 |
| `panel=0` | 去掉条目半透明底板，只留文字 |
| `title=0` | 隐藏歌单标题行；也可以写 `title=今晚随机唱见` 自定义 |
| `preview=1` | 加一层示意背景，方便在浏览器里看效果（直播别加） |

### 配色

| 参数 | 说明 |
|---|---|
| `theme` | `aurora` / `sakura` / `midnight` / `neon` / `sunset` / `light` |
| `accent` | 主色：标题高亮、直播间按钮、头像描边、正在播放标记 |
| `accent2` | 主色浅色端（头像与色卡渐变） |
| `bg` | 条目底板色 |
| `bgOpacity` | 底板通透度 `0`–`1` |
| `color` / `sub` | 歌名 / 歌手文字色 |
| `tagAlpha` / `tagSat` / `tagLight` | 标签的不透明度、饱和度、明度 |

颜色写任意 hex 即可（URL 里 `#` 要写成 `%23`）。没写的项沿用所选主题的值，所以**改一个不会连带动其它**。

## 主题与配色怎么设计的

三件事值得说清楚，因为它们直接决定你后面改起来顺不顺手：

1. **六套预设主题打底，单点颜色可覆盖。** 主题是一组值（主色 / 底板 / 文字 / 标签色感 / 阴影强度），URL 参数只在需要时覆盖其中一项。想做浅色歌单就用 `theme=light`，不用逐项挑色。
2. **标签保留自己的色相，只让饱和度与明度跟着主题走。** 所以换主题时整排标签会一起变调，不会出现「一个粉一个绿各说各话」。写数据里没出现过的新标签名（比如「粤语」「打歌」）会自动分配一个稳定色相；想钉死某一条就写 `"color": "#FF0000"`。
3. **主色上的文字色是算出来的，不是写死的。** `--accent-fg` 会按主色亮度自动决定用深字还是白字，所以你把 `accent` 改成很深的蓝，按钮上的字会自动翻成白色。

## 数据格式

`streamers/yuki.json`：

```json
{
  "id": "yuki",
  "name": "星野雪",
  "handle": "HoshinoYuki",
  "avatar": "assets/avatars/yuki.jpg",
  "bio": "每晚 20:00 开播｜日语流行与唱见",
  "intro": "主页上展示的完整简介",
  "tags": ["日语", "唱见", "治愈"],
  "theme": "aurora",
  "accent": "#7C9CFF",
  "bilibili": {
    "space": "https://space.bilibili.com/100001",
    "live": "https://live.bilibili.com/200001"
  },
  "title": "今日歌单",
  "updated": "2 小时前",
  "songs": [
    { "tag": "日语", "name": "夜に駆ける", "artist": "YOASOBI" }
  ]
}
```

`data/streamers.json` 是首页用的名册（站点标题 + 每位主播的展示信息，不含歌曲），首页会再各读一份 `streamers/<id>.json` 统计曲目数。

内置标签色相：`日语` `中文` `英文` `高音` `韩语` `电音` `粤语` `纯音乐` `RAP`。

## 设计要点

- **所有尺寸锚定在歌名字号上。** 标签、歌手、间距、圆角、阴影全部按 `--fs` 等比缩放，所以调 `size` 是整体放大，不会出现「字大了标签还那么小」的割裂感。
- **大字版的身份行是单独一套比例。** 歌名放大到 34px 时，头像和按钮会相对收缩（`1.55×` 而不是 `2.38×` 字号），否则底部整条会被撑得又高又笨。
- **文字阴影跟随字号**（用 `em` 计算），调到多大都不会糊在复杂画面上；浅色主题下会自动换成贴着字形的一圈细白晕，避免深色文字被阴影漂白。
- **长歌名靠 `overflow-wrap: anywhere` 自然换行**，不截断也不撑破容器，无空格的英文长名同样能断。

## 文件结构

```
index.html                 首页 · 主播大厅
profile.html               主播个人主页
overlay.html               悬浮层（OBS 用的就是它）
studio.html                配置台：调参 + 实时预览 + 生成地址
data/streamers.json        站点配置 + 主播名册
streamers/<id>.json        每位主播的信息与歌单（改这个）
assets/theme.js            6 套主题预设 + 颜色工具
assets/common.js           参数解析 / 数据加载 / 标签配色
assets/overlay.css         悬浮层样式（三套外观）
assets/overlay.js          悬浮层逻辑
assets/site.css            首页 / 主页 / 配置台样式
assets/home.js             首页逻辑
assets/profile.js          主播主页逻辑
assets/studio.js           配置台逻辑
```

> 头像不是必填项。不配置时用「名字首字 + 主色渐变」自动生成，配色跟着该主播的 `accent` 走；
> 想换成真实图片，新建 `assets/avatars/` 放进去，再在 `streamers/<id>.json` 里加 `avatar` 字段。
>
> 本页面的数据是用 `fetch` 读的，所以**必须通过 http(s) 访问**（本地用
> `python -m http.server` 起一个，或直接推到 GitHub Pages）。直接用
> `file://` 双击打开会读不到 json。
